1. Introduction

VibeVault is a ThemeForest-ready HTML5 template designed for premium Karaoke Bars, Private Party Lounges, VIP Music Suites, and Multi-Branch Entertainment Venues.

Built with HTML5, Vanilla JavaScript / ES6, Tailwind CSS, Bootstrap Icons, and CSS3 animations. Completely frontend-driven without requiring backend installations or database servers to preview and demo.

4. Changing Colors & Fonts

All color tokens are organized in assets/css/main.css under the :root declaration: 

:root {
  --bg-dark: #0B0914;        /* Deep midnight indigo base */
  --bg-surface: #120E24;     /* Card surfaces */
  --neon-pink: #FF007F;      /* Primary accent for CTAs */
  --neon-cyan: #00F0FF;      /* Secondary glow accent */
  --font-display: 'Outfit';  /* Headings font */
  --font-body: 'Inter';      /* Body font */
}

5. Replacing Photographic Assets

Every photo is organized in a single configuration file at assets/js/data/images.js. To replace with local venue photos, simply edit the URL strings in that file: 

const VIBE_IMAGES = {
  rooms: {
    retro80s: 'assets/images/rooms/retro80s.jpg',
    kpopStudio: 'assets/images/rooms/kpop.jpg'
  }
};

6. LocalStorage & Resetting Demo Data

Bookings made in the stepper wizard immediately save to LocalStorage, decrement slot availability, and appear in the "My Reservations" tab. To restore initial sample data, go to Dashboard → App Settings → Reset Demo Data.
